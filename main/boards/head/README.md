# 智慧头（head）

主控为 ESP32-S3 N16R8，无显示屏、无 LED。音频输出使用 ES8311，
输入使用 ES7210：MIC1 为左侧麦克风，MIC2 为右侧麦克风，MIC3 接
ES8311 OUTP/OUTN 作为 AEC 参考，MIC4 不参与当前固件的采集。

MIC1/MIC2 收音孔朝向正前方，中心距约 48 mm。固件使用 ESP-SR DOA
进行声源定位，日志角度以正前方为 0°、左侧为负、右侧为正。双麦定位
存在前后镜像歧义，设备播放声音期间会冻结最后有效角度。

## 构建

```powershell
python scripts/release.py head
```

设备端 AEC 默认启用。Boot 单击切换对话；启动阶段单击进入配网；
空闲状态双击切换设备端 AEC。

## 硬件验证

首次烧录后应确认：

1. ES8311、ES7210 均能正常初始化。
2. 扬声器和 PA GPIO42 工作正常。
3. 输入的三个通道依次为 MIC1、MIC2 和 MIC3 回采。
4. 声源位于左、正前、右时，日志角度依次为负、接近 0、正。
5. 播放 TTS 时角度冻结，播放结束后恢复更新。
6. 开启声源定位后实时对话和 AEC 仍能正常工作。
