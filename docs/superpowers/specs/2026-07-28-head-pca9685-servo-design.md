# Head 板 PCA9685 舵机驱动设计

## 目标

为 ESP32-S3 Head 板增加 PCA9685 舵机驱动，并在启动时让 PCA9685 CH1
上的舵机执行一次测试动作。GPIO0 改作 PCA9685 电源使能，因此取消原有
BUTTON 功能。

## 硬件配置

- PCA9685 I2C 总线：I2C_NUM_0
- SDA：GPIO8
- SCL：GPIO7
- I2C 地址：0x40
- 总线速率：400 kHz
- 电源使能：GPIO0，低电平有效
- 舵机 PWM 频率：50 Hz
- 音频 Codec 继续使用 I2C_NUM_1、GPIO13/14

GPIO0 是 ESP32-S3 启动绑带引脚。硬件必须保证芯片复位采样期间 GPIO0
保持高电平，避免进入下载模式。软件初始化时先将 GPIO0 输出高电平关闭
PCA9685 电源，完成 GPIO 与总线准备后再拉低使能。

## 软件结构

在 `main/boards/head/` 中增加 `Pca9685` 类，继承公共 `I2cDevice`：

- 初始化 MODE1、MODE2 和 PRESCALE，输出频率设为 50 Hz。
- 提供 16 通道原始 PWM 设置接口。
- 提供微秒脉宽接口。
- 提供角度接口，将 0–180° 映射为 500–2500 μs。
- 提供单通道关闭和全部通道关闭接口。
- 校验通道、脉宽和角度参数，I2C 错误向调用者返回。

`HeadBoard` 负责 GPIO0 电源时序、第二条 I2C 总线以及 PCA9685 实例的
生命周期。原 `Button` 成员、初始化和点击回调全部移除。

## 启动与测试流程

1. GPIO0 输出高电平，关闭 PCA9685 电源。
2. 初始化音频 Codec I2C 总线。
3. 初始化 GPIO7/8 上的舵机 I2C 总线。
4. GPIO0 拉低，使能 PCA9685 电源，并等待芯片稳定。
5. 初始化 PCA9685 为 50 Hz。
6. PCA9685 CH1（第二路输出，索引 1）依次转到
   `0° → 90° → 180° → 90°`，每步间隔约 800 ms。
7. 测试完成后保持 90°。

初始化或测试动作失败时记录错误，但不阻塞网络与音频服务启动。

## 文档与验证

- 更新 Head 板 README，删除 BUTTON 交互并记录 PCA9685 接线。
- 构建 `head` 板固件，确认没有编译和链接错误。
- 上板确认正常启动、不会进入下载模式。
- 测量 CH1 PWM 为约 50 Hz，并观察舵机只执行一次测试序列。
- 确认 Codec I2C、音频采集、声源定位和网络功能不受影响。

## 非目标

- 不增加 MCP 舵机控制工具。
- 不实现持续往返动作或声源跟踪联动。
- 不改动现有音频 Codec 总线及音频处理流程。
