# Head 板 PCA9685 舵机驱动设计

## 目标

为 ESP32-S3 Head 板增加 PCA9685 舵机驱动，让 PCA9685 CH1 上的舵机
上电恢复到中位 105°，并根据声源定位结果转向声源。GPIO0 改作 PCA9685
电源使能，因此取消原有 BUTTON 功能。

## 硬件配置

- PCA9685 I2C 总线：I2C_NUM_0
- SDA：GPIO8
- SCL：GPIO7
- I2C 地址：0x40
- 总线速率：400 kHz
- 电源使能：GPIO0，低电平有效
- 舵机 PWM 频率：50 Hz
- 音频 Codec 继续使用 I2C_NUM_1、GPIO13/14

GPIO0 是 ESP32-S3 启动绑带引脚。硬件必须保证芯片复位采样期间 GPIO0
保持高电平，避免进入下载模式。软件初始化时先将 GPIO0 输出高电平关闭
PCA9685 电源，完成 GPIO 与总线准备后再拉低使能。

## 软件结构

在 `main/boards/head/` 中增加 `Pca9685` 类，继承公共 `I2cDevice`：

- 初始化 MODE1、MODE2 和 PRESCALE，输出频率设为 50 Hz。
- 提供 16 通道原始 PWM 设置接口。
- 提供微秒脉宽接口。
- 提供角度接口，将 0–180° 映射为 500–2500 μs。
- 提供单通道关闭和全部通道关闭接口。
- 校验通道、脉宽和角度参数，I2C 错误向调用者返回。

`HeadBoard` 负责 GPIO0 电源时序、第二条 I2C 总线以及 PCA9685 实例的
生命周期。原 `Button` 成员、初始化和点击回调全部移除。

声源定位回调不直接访问 I2C，只将最新有效角度覆盖写入长度为 1 的队列。
Head 板专用的舵机任务消费队列并控制 PCA9685，避免阻塞 `sound_locator`
任务。舵机任务只保留最新目标，不追赶过期定位结果。

## 启动流程

1. GPIO0 输出高电平，关闭 PCA9685 电源。
2. 初始化音频 Codec I2C 总线。
3. 初始化 GPIO7/8 上的舵机 I2C 总线。
4. GPIO0 拉低，使能 PCA9685 电源，并等待芯片稳定。
5. 初始化 PCA9685 为 50 Hz。
6. 将 PCA9685 CH1（第二路输出，索引 1）恢复到中位 105°并等待 2 秒。
   上电物理位置未知且没有反馈，因此回中动作无法由软件严格限速。
7. 启动声源跟随任务，后续动作限制为 20°/秒。

若回中写入失败，跟随任务仍会启动；首次有效定位直接建立软件位置，该次
动作无法严格限速。未知位置和正常跟随的 I2C 写入尝试均限制为最高 5 Hz。

初始化失败时记录错误，但不阻塞网络与音频服务启动。

## 声源定位联动

定位角度定义为左负右正，范围 `-90°～+90°`。舵机按以下公式线性映射：

声源角度在中位两侧分别线性映射到舵机角度，并限制在 `75°～135°`。

- 左极限：声源 `-90°`，舵机 `75°`
- 中位：声源 `0°`，舵机 `105°`
- 右极限：声源 `+90°`，舵机 `135°`

舵机目标相对当前位置至少变化 1°时才更新，连续两次 I2C 输出至少间隔
200 ms。每次最多移动 4°，将聊天期间的最大转速限制为 20°/秒；移动中
收到新定位结果时立即替换目标，并从下一步开始转向新目标。定位器没有输出
有效声源或设备正在播放声音时不产生新目标，舵机完成当前目标后保持角度。
I2C 写入失败时记录错误并继续等待后续目标，不阻塞定位、音频和网络任务。

## 日志与项目说明

运行时不打印声源方向和跟随分步角度，也不计算或打印三通道输入电平与相关
性统计，避免额外 CPU 开销和持续输出影响串口可读性。保留初始化成功摘要、
任务启动信息、警告及所有错误日志。

根目录 `README.md` 的 `# audio-test` 区域介绍本项目的 Head 板硬件、实时
聊天、音频通道、声源定位、PCA9685 舵机跟随、角度与速度配置、接线和构建
命令。原分隔线及其下方的上游项目文档保持不变。

## 文档与验证

- 更新 Head 板 README，删除 BUTTON 交互并记录 PCA9685 接线。
- 构建 `head` 板固件，确认没有编译和链接错误。
- 上板确认正常启动、不会进入下载模式。
- 确认上电后 CH1 将舵机恢复到中位 105°。
- 测量 CH1 PWM 为约 50 Hz，并观察舵机只在 75°～135°之间运动。
- 从设备左侧、正前和右侧发声，确认舵机分别趋近 75°、105°和 135°。
- 确认小于 1°的目标变化不会引起舵机抖动，更新频率不超过 5 Hz。
- 确认每 200 ms 位移不超过 4°，左右全程用时不短于约 3 秒。
- 确认无声和设备播放期间舵机保持最后角度。
- 确认 Codec I2C、音频采集、声源定位和网络功能不受影响。

## 非目标

- 不增加 MCP 舵机控制工具。
- 不实现持续往返动作。
- 不改动现有音频 Codec 总线及音频处理流程。
