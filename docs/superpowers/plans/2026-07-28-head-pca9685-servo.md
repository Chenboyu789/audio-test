# Head PCA9685 Servo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a 16-channel PCA9685 servo driver to the Head board and run a one-shot CH1 servo motion test at startup.

**Architecture:** A board-local `Pca9685` class derives from the existing `I2cDevice`, but uses the protected device handle directly so register operations can return `esp_err_t` instead of aborting. `HeadBoard` owns the second I2C bus and driver, controls the active-low GPIO0 power enable, and removes all button behavior.

**Tech Stack:** C++17, ESP-IDF GPIO and new I2C master APIs, FreeRTOS delay APIs.

---

### Task 1: Add PCA9685 driver

**Files:**
- Create: `main/boards/head/pca9685.h`
- Create: `main/boards/head/pca9685.cc`

- [ ] **Step 1: Define the public interface**

Declare `Pca9685(i2c_master_bus_handle_t, uint8_t)`, `Initialize(uint16_t = 50)`,
`SetPwm(uint8_t, uint16_t, uint16_t)`, `SetPulseWidthUs(uint8_t, uint16_t)`,
`SetAngle(uint8_t, float)`, `DisableChannel(uint8_t)`, and `DisableAll()`.
Store the configured frequency for pulse-to-count conversion. Validate channel
indexes against 0–15, PWM counts against 0–4095, pulse widths against one PWM
period, and angles against 0–180°.

- [ ] **Step 2: Implement register access and initialization**

Use `i2c_master_transmit` and `i2c_master_transmit_receive` on the inherited
`i2c_device_` handle and return their `esp_err_t` values. Initialize MODE1 with
auto-increment, set MODE2 to totem-pole output, calculate
`prescale = round(25 MHz / (4096 * frequency)) - 1`, enter sleep before writing
PRESCALE, then restart after waking. Delay 500 microseconds between wake and
restart.

- [ ] **Step 3: Implement PWM and servo conversions**

Write each channel's four LED registers in one auto-increment transaction.
Convert microseconds to counts with rounded integer arithmetic:
`counts = (pulse_us * frequency_hz * 4096 + 500000) / 1000000`.
Map 0–180° linearly to 500–2500 microseconds. Disable a channel using the
FULL_OFF bit and disable all outputs through ALL_LED registers.

- [ ] **Step 4: Perform static driver checks**

Confirm no unchecked channel can address beyond `LED0_ON_L + 4 * 15`, the
prescale range is 3–255, and every I2C operation returns an error to its caller.

### Task 2: Integrate the driver into HeadBoard

**Files:**
- Modify: `main/boards/head/config.h`
- Modify: `main/boards/head/head_board.cc`

- [ ] **Step 1: Replace button configuration**

Remove `BOOT_BUTTON_GPIO`. Add GPIO7/GPIO8 servo I2C pin constants, GPIO0
active-low power-enable, address `0x40`, frequency `50`, and test channel `1`.

- [ ] **Step 2: Remove button behavior**

Delete the `button.h` and `application.h` includes, `Button` member,
`InitializeButtons()`, constructor initializer, and all click/double-click
callbacks.

- [ ] **Step 3: Add power and I2C initialization**

Configure GPIO0 as an output with initial level high. Create I2C_NUM_0 using
SDA GPIO8 and SCL GPIO7 with internal pull-ups. Pull GPIO0 low and wait 10 ms
before constructing and initializing `Pca9685`.

- [ ] **Step 4: Add the startup motion test**

When PCA9685 initialization succeeds, set CH1 to 0°, 90°, 180°, and 90° with
800 ms between commands. Stop the sequence on the first error and log it.
Do not fail `HeadBoard` construction when PCA9685 initialization or motion fails.
